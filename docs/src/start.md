

# Getting started

**Last update**: 20261025-1

This is a summary of links containing the introductory material for the O2 analysis framework:

* Official documentation for the ALICE O2 Analysis Framework is maintained at this [link](https://aliceo2group.github.io/analysis-framework/) . In particular:
		
	1. )  the low-level O2 tables to which you can subscribe directly in the analysis code are published at this [link](https://aliceo2group.github.io/analysis-framework/docs/datamodel/ao2dTables.html). These tables are defined directly in the "AO2D.root" data files, and as such, can be directly processed in the analysis code; 

	2. ) the helper-task tables, i.e. the tables produced at run-time during analysis and whose tasks you have to include in the workflow explicitly, are at this [link](https://aliceo2group.github.io/analysis-framework/docs/datamodel/helperTaskTables.html) . 

* The latest O2 tutorial, November 2025: [indico](https://indico.cern.ch/event/1574136/timetable/) . in case you do not have access, i.e. if you are still not officially a member of the ALICE Collaboration, I have uploaded only the introductory presentations, at this public [link](https://cernbox.cern.ch/s/akoLJYlc8Ovk4aZ) .
